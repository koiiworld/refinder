# 서이추 도우미 (반자동, 추천)

평소 쓰는 크롬/엣지 안에서 동작하는 **확장 스크립트**입니다. Python 설치가 필요 없습니다.

- 프로그램이 브라우저를 조종하지 않아서 **로그아웃되지 않습니다**. 로그인은 평소처럼 하세요.
- 하는 일: 검색어로 이웃 후보 찾기 → 신청창 열기 → **서로이웃 선택 + 멘트 자동 입력**
- **[확인](보내기)은 직접 누릅니다.** 자동으로 보내지 않습니다.

## 설치 (처음 한 번, 2분)

1. 크롬 웹스토어에서 **Tampermonkey** 확장 프로그램을 설치합니다.
2. 크롬 주소창에 `chrome://extensions` 입력 → 오른쪽 위 **개발자 모드** 켜기
   (최신 크롬은 Tampermonkey 세부정보에서 **사용자 스크립트 허용**도 켜야 합니다.)
3. 아래 주소를 열면 Tampermonkey 설치 화면이 뜹니다 → **설치** 클릭
   `https://raw.githubusercontent.com/koiiworld/refinder/claude/seoichoo-automation-program-50awjg/seoichoo/userscript/seoichoo-helper.user.js`
   - 설치 화면이 안 뜨면: Tampermonkey 아이콘 → 새 스크립트 만들기 → 이 파일 내용을 붙여넣고 저장

## 사용법

1. 평소처럼 네이버에 로그인합니다.
2. **https://section.blog.naver.com** 에 접속하면 오른쪽 아래에 **서이추 도우미** 창이 뜹니다.
3. 검색어(쉼표/줄바꿈 구분)와 공용 멘트를 적고 **대상 찾기**를 누릅니다.
   멘트는 **한 줄에 하나씩** 여러 개 적으면 신청할 때마다 무작위로 골라 씁니다 (바로 전 멘트는 피함).
   멘트에 `{닉네임}`을 넣으면 상대 닉네임으로 바뀝니다.
4. **다음 신청창 열기** → 작은 창이 열리고 서로이웃 선택과 멘트 입력이 자동으로 됩니다.
5. 내용을 확인하고 **[확인]을 직접 누릅니다.** 신청 불가 블로그면 **건너뛰기**를 누르세요.
6. 다시 **다음 신청창 열기**를 누릅니다. 너무 빠르게 보내지 않도록 버튼이 30~60초 동안 잠깁니다
   (최소 간격은 창에서 바꿀 수 있습니다).

## 검색 결과 묶음

- **대상 찾기**를 누를 때마다 새 '검색 결과 묶음'이 생기고 목록이 그 결과로 바뀝니다.
- 목록 위 `‹ [날짜 · 검색어 · 인원] ›` 칸에서 이전 묶음을 골라 다시 볼 수 있습니다 (계정 탭마다 최근 10개).
- 자동 보내기와 다음 신청창 열기는 지금 보고 있는 묶음에만 적용됩니다.
- 이미 보냈거나 건너뛴 사람은 새 검색에서 빠지고, 한 묶음에서 보내면 다른 묶음에도 '보냄'으로 보입니다.
- **묶음 삭제**는 지금 보는 묶음만 지우고, 보낸 기록은 남깁니다.

## 자동 보내기 (체크한 사람)

1. 대상 찾기 후 목록에서 보낼 사람을 체크합니다 (**전체 선택** / **선택 해제** 가능).
2. **체크한 사람 자동 보내기**를 누르면 한 명씩 신청창을 열고, 멘트를 무작위로 넣은 뒤 **확인까지 자동으로** 누릅니다.
3. 사람 사이 간격은 `신청 간격` 최소~최대 사이에서 무작위로 정해집니다 (기본 60~180초, 최소 20초).
4. 서로이웃 신청을 받지 않는 사람, 이미 이웃인 사람, **이웃이 5,000명이 차서 더 못 받는 사람**은 자동으로 건너뜁니다.
5. 한 번에 20명, 하루 100명이 되거나 네이버가 한도 안내를 띄우면 멈춥니다. 버튼을 다시 누르면 언제든 멈춥니다.
6. 자동 보내기 중에는 신청 창을 닫지 마세요.
7. 다른 작업을 하는 동안 크롬이 네이버 탭을 쉬게 하거나 새로고침해도, 탭이 다시 열리면 이어서 보냅니다 (20분 안).
   더 확실하게 하려면 크롬 **설정 → 성능 → 메모리 절약 → 항상 활성 상태로 유지할 사이트**에 `section.blog.naver.com`을 추가하세요.

한 명씩 직접 확인하며 보내고 싶으면 **다음 신청창 열기**를 쓰면 됩니다.

## 수락률

- 도우미 아래쪽 **수락 확인**을 누르면 내 블로그 '내가 추가한 이웃' 목록을 읽어서, 보낸 사람 중 **서로이웃**이 된 사람을 셉니다.
- `보낸 40명 중 수락 12명 (30%)`처럼 계정 전체와 검색 결과 묶음별 수락률이 나오고, 목록에서 수락한 사람은 초록색 **수락**으로 바뀝니다.
- 자동으로 못 읽으면 '내가 추가한 이웃' 페이지를 열어 줍니다. 그 페이지에서 쪽을 넘기면 도우미가 읽어 옵니다.

## 계정별 탭

- 도우미 창 위쪽 탭 하나가 네이버 계정 하나입니다. **+** 로 추가(최대 3개), **×** 로 닫습니다.
- 탭마다 검색어, 멘트, 보낸 목록, 하루 100명 한도를 따로 기억합니다.
- 탭은 처음 신청창을 열 때 로그인 중인 네이버 아이디와 자동으로 연결되고, 탭 이름도 그 아이디로 바뀝니다.
  탭 이름을 두 번 누르면 이름을 바꿀 수 있어요.
- 다른 계정으로 로그인한 상태에서 맞지 않는 탭을 고르면 경고가 뜨고 신청창이 열리지 않습니다.
- 탭을 닫으면 그 탭의 보낸 목록도 지워집니다.

## 안전장치

- 하루 100명이 되면 더 열리지 않습니다 (네이버 정책).
- 20명마다 쉬어 가라고 알려줍니다.
- 보낸 블로그, 건너뛴 블로그, 신청 불가 블로그는 기록되어 다음 검색에서 빠집니다.
- 신청창에서 입력칸을 못 찾으면 멘트를 클립보드에 복사해 두니 `Ctrl+V`로 붙여넣으면 됩니다.
- 팝업이 막히면 주소창 오른쪽에서 `section.blog.naver.com`의 팝업을 허용하세요.
