# 서이추 Windows 프로그램

검색어로 네이버 블로그 후보를 찾고, **직접 선택한 대상**에게 서로이웃 신청을 순서대로 보내는 프로그램입니다.
비밀번호는 프로그램에 입력하지 않고 열린 Chrome/Edge에서 직접 로그인합니다.

## 가장 쉬운 실행 방법 — Python 설치 필요 없음

1. **[최신 Windows 버전 받기](https://github.com/koiiworld/refinder/releases/latest)** 를 엽니다.
2. Assets에서 **`seoichoo-windows-x64.zip`** 을 받습니다. `Source code`는 실행 파일이 아닙니다.
   - [ZIP 바로 받기](https://github.com/koiiworld/refinder/releases/latest/download/seoichoo-windows-x64.zip)
3. ZIP을 마우스 오른쪽 클릭 → **모두 압축 풀기** 합니다.
4. 풀린 폴더 안의 **`seoichoo.exe`** 를 더블클릭합니다.
5. PC에 설치된 **Chrome → Edge** 순으로 브라우저를 엽니다. 브라우저를 ZIP에 넣거나 자동으로 다운로드하지 않습니다.

Windows 10/11 64비트용입니다. Chrome/Edge 중 하나는 설치되어 있어야 합니다.
다운로드한 ZIP 안에서 바로 실행하지 말고, `문서/seoichoo`처럼 쓰기 가능한 폴더에 모두 풀어 주세요.
Python은 **exe를 만드는 사람에게만** 필요합니다. exe를 사용하는 사람은 Python이나 터미널을 설치할 필요가 없습니다.

> 릴리스 페이지에 ZIP이 없으면 첫 Windows 빌드가 아직 끝나지 않았거나 실패한 것입니다.
> [빌드 진행 확인](https://github.com/koiiworld/refinder/actions/workflows/seoichoo-release.yml)

## 먼저 알아둘 검증 범위

사용자가 실제 로그인·신청 성공을 확인했고, 제공된 완료 화면의 문구를 결과 판별에 반영했습니다. 개발자가 실계정으로 직접 검증한 것은 아니며, 계정·화면별 차이는 남아 있습니다.
Windows 릴리스는 모의 폼/단위 테스트와 **포장된 exe의 Tk GUI·Playwright 드라이버 자체 실행 검사**를 통과한 뒤에만 게시됩니다.
이 검사는 실제 네이버 화면 선택자가 맞다는 뜻은 아닙니다. 자세한 범위는 [VALIDATION.md](VALIDATION.md)를 확인하세요.

## 처음에는 2~3명으로 확인하기

1. `브라우저 열기` → 열린 브라우저에서 네이버 로그인 → `로그인 확인`.
2. 검색어와 신청 문구를 적고 `대상 찾기`를 누릅니다. `{닉네임}`은 상대 닉네임으로 바뀝니다.
3. **선택 전체 해제** 후 실제로 확인할 후보 2~3명만 선택합니다. **1회 최대**도 `2` 또는 `3`으로 설정합니다.
4. 필요하면 먼저 **`신청 폼 진단(전송 안 함)`** 을 누릅니다. 첫 선택 후보의 폼을 열어 요소 정보만 `diagnostics.json`에 저장하고, 신청은 보내지 않습니다.
5. `서이추 자동 신청` → 대상 수·신청 간격을 확인하고 진행합니다.
6. 네이버에서 보낸 신청 목록을 직접 확인합니다. 프로그램 표시만으로 성공 여부를 단정하지 마세요.
7. `직접 확인 필요` 또는 오류가 나오면 자동 신청을 멈춥니다. 그 상태에서 반복 신청하지 말고, 실제 신청 여부를 확인하세요.

기본값은 **1회 최대 20명**, **간격 30~120초**, **프로그램 일일 상한 100명**입니다.
실제 네이버 정책·계정 상태에 따라 더 적게 제한될 수 있습니다. 프로그램 설정이 서비스의 허용량을 보장하지는 않습니다.
완료가 불확실한 전송은 중복 신청을 막기 위해 재신청 대상에서 제외하고 일일 횟수에도 보수적으로 포함합니다.
`중지`를 누르면 현재 작업이 끝난 뒤 멈춥니다. 공용 PC에서는 사용 후 `네이버 로그아웃`을 누르세요.

## 파일과 개인정보

exe가 있는 폴더에 다음 파일이 생깁니다.

- `history.json`: 신청 결과와 일일 횟수
- `settings.json`: 검색어·신청 문구·설정
- `browser_profile/`: 이 프로그램에서 사용한 브라우저 로그인 세션
- `diagnostics.json`: 직접 진단 버튼을 눌렀을 때만 생성되는 폼 요소 정보

`browser_profile/`, 비밀번호, 쿠키를 다른 사람에게 보내지 마세요. 진단 파일에는 비밀번호·쿠키·입력값·페이지 본문을 넣지 않습니다.
파일을 공유하기 전에는 본인도 내용을 확인하세요. 배포 ZIP에는 exe·설명서·검증 안내·체크섬만 들어갑니다.
업데이트할 때는 프로그램과 브라우저를 닫고 새 exe를 기존 폴더에 덮어쓰면 기존 기록·설정을 이어서 씁니다.

## 선택자가 달라서 신청이 안 되는 경우

실제 로그인된 폼을 확인한 뒤 같은 폴더의 `selectors.json`에서 선택자를 추가할 수 있습니다.
기존 기본값보다 먼저 시도합니다. 아래 값은 예시이며 현재 네이버 화면에 맞는지는 직접 검증해야 합니다.

```json
{
  "both_buddy": ["label:has-text('서로이웃을 신청합니다')"],
  "message": ["textarea#실제입력란ID"],
  "submit": ["button:has-text('확인')"]
}
```

신청 문구 입력에 실패하면 전송하지 않습니다. 화면 이동이나 단순 확인 질문을 성공으로 간주하지 않고,
명시적인 완료 문구를 확인하지 못하면 `직접 확인 필요`로 남깁니다. 로그인·보안 확인이 필요하면 브라우저에서 직접 처리하세요.
자동화 사용은 네이버 이용약관과 계정 제한 정책을 확인한 뒤 본인 책임으로 사용하세요.

## 소스 코드로 실행 / 직접 exe 만들기

일반 사용자는 위 ZIP만 받으면 됩니다. 개발자용 실행은 Python 3.10 이상에서 `start.bat`(Windows) 또는 `./start.sh`(macOS/Linux)를 사용합니다.
Windows `start.bat`도 PC의 Chrome/Edge를 사용합니다.

Windows에서 직접 빌드하려면 Python 3.12 설치 후 **`build_exe.bat`** 를 더블클릭합니다.
성공하면 `dist/seoichoo-windows-x64.zip`과 ZIP의 SHA-256 체크섬이 만들어집니다.

GitHub 자동 빌드는 `.github/workflows/seoichoo-release.yml`에 있습니다.
지정 브랜치의 이 폴더/워크플로 변경을 push하면 `windows-latest`에서 빌드·검증·ZIP 포장 후 Releases에 게시합니다.
수동 실행은 워크플로가 기본 브랜치에 등록된 경우 Actions의 **Run workflow**에서 지정 브랜치를 골라 실행할 수 있습니다.
브라우저 로그인 정보나 네이버 비밀번호를 GitHub Secrets에 넣을 필요가 없습니다.

```text
pyinstaller --onefile --windowed --name seoichoo --collect-all playwright seoichoo.py
```
