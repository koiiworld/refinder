# 서이추 자동 프로그램

네이버 블로그 **서로이웃 추가(서이추)** 를 자동으로 신청해 주는 프로그램입니다.
검색어로 내 분야 블로거를 찾고, 공용 신청문구로 선택한 후보에게 차례대로 서이추를 신청합니다.

## 설치 / 실행

1. [Python 3.10 이상](https://www.python.org) 설치 (설치 시 **Add python.exe to PATH** 체크)
2. 이 폴더에서 **`start.bat`** 더블클릭 (맥/리눅스는 `./start.sh`)
   - 처음 실행 때 필요한 패키지(Playwright)와 브라우저가 자동 설치됩니다.

## 사용 방법

1. **로그인**
   1. `브라우저 열기` → 열린 크롬 창에서 네이버 로그인 (비밀번호는 프로그램이 저장·전송하지 않음)
   2. `로그인 확인` → "내 블로그: 아이디" 가 뜨는지 확인
2. **대상 찾기**
   1. 검색어 입력 (줄바꿈이나 쉼표로 구분, 10개 정도 추천. 예: `나는솔로1회, 나는솔로2회 ...`)
   2. 공용 신청문구 작성 — `{닉네임}` 을 넣으면 상대 닉네임으로 바뀝니다
   3. `대상 찾기` → 검색어 관련 글을 쓴 블로거가 후보 목록에 채워집니다
3. **자동 신청**
   1. `후보 전체 선택` (행 클릭으로 개별 선택/해제 가능)
   2. `서이추 자동 신청` → 설정한 간격(기본 8~20초 랜덤)으로 하나씩 신청, `중지` 로 언제든 멈춤
4. 작업이 끝나면 `네이버 로그아웃`

## 동작 규칙

- 네이버 정책상 서이추는 **하루 100명**까지만 신청 가능 → 프로그램도 하루 100명(설정으로 더 낮출 수 있음)에서 자동으로 멈춥니다.
- 신청 결과는 `history.json` 에 기록되어, 이미 신청했거나 이미 이웃·서이추 불가인 블로그는 다음 검색에서 제외됩니다.
- 서로이웃 그룹 인원이 가득 차면 신청이 안 될 수 있습니다. 그 경우 블로그의 이웃 그룹을 확인하세요.
- 로그인 정보는 이 폴더의 `browser_profile/` 에만 남습니다. 공용 PC라면 사용 후 꼭 로그아웃하세요.

## 문제 해결

네이버 화면 구조가 바뀌어 "서로이웃 선택 항목을 찾지 못했습니다" 같은 오류가 나면
이 폴더에 `selectors.json` 을 만들어 선택자를 추가할 수 있습니다 (기존 값보다 먼저 시도됨).

```json
{
  "both_buddy": ["label:has-text('서로이웃을 신청합니다')"],
  "message": ["textarea"],
  "submit": ["button:has-text('확인')"]
}
```

## 주의

자동화 프로그램 사용은 네이버 이용약관에 어긋날 수 있고, 짧은 간격으로 대량 신청하면
스팸으로 분류되어 계정이 제한될 수 있습니다. 신청 간격을 너무 줄이지 말고 본인 책임 하에 사용하세요.
