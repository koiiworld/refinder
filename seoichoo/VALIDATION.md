# 검증 범위

## 릴리스 게시 전 자동 검사

GitHub Actions Windows 빌드는 아래 검사가 성공한 경우에만 ZIP을 게시합니다.

- Python 소스 단위 테스트: 기본값, Worker 단일 스레드, 신청 기록·불확실 전송 횟수, 공개 배포 파일/체크섬
- 로컬 모의 폼 테스트: 숨긴 라디오 대신 라벨 선택, 신청 문구 입력 실패 시 전송 안 함, 명시적 완료/불명확 결과 구분
  - 시스템 Chrome/Edge가 없으면 이 브라우저 테스트는 생략 표시됩니다. 실제 네이버 검증이 아닙니다.
- PyInstaller `--onefile --windowed --collect-all playwright` 빌드
- **exe 자체 실행:** Tk GUI 생성 + 전용 Worker에서 패키징된 Playwright 드라이버 시작/종료
  - 검사 중 네이버에 접속하거나 신청하지 않습니다.
  - 임시 폴더에서 실행하므로 사용자 신청 기록·설정은 수정하지 않습니다.
  - 외부 Python 경로를 PATH에서 제거한 상태로 exe를 실행합니다.
- ZIP에는 `seoichoo.exe`, README, 이 문서, SHA-256 목록만 포함

## 아직 실계정 검증이 필요한 항목

- 네이버 로그인 확인 / 내 블로그 ID 인식
- `BuddyAddForm.naver`의 실제 라디오·문구·신청 버튼 선택자
- 실제 성공·거절·신청 한도·그룹 제한 문구
- 실계정으로 선택한 2~3명 신청 후 네이버에서 결과 대조

이 클라우드의 네이버 접속은 네트워크 정책으로 차단되어 있고 로그인된 실계정이 없어 위 항목을 확인하지 못했습니다.
`diagnostics.json`은 선택자 조정용 메타데이터이며, 신청 결과를 증명하는 자료는 아닙니다.
기존 검색 API는 이전 작업에서 확인한 상태를 인계받았으며 이번 빌드 작업에서 다시 실서비스로 검증하지 않았습니다.
