# 릴스 읽어줘

링크를 받으면 영상을 직접 "보고 듣고" 설명한다. 도구는 이 저장소에 이미 있다 (맥 전용).

- 영상 받기: `content-office/bin/yt-dlp`
- 화면 뽑기: `content-office/node_modules/ffmpeg-static/ffmpeg`
- 받아쓰기: `~/.ai-content-office/whisper-venv/bin/python content-office/scripts/transcribe.py` (faster-whisper, 무료)

## 순서

1. 저장소 루트에서 실행한다 (링크가 여러 개면 한 번에):

   ```
   zsh .claude/skills/reel-reader/read-reel.sh "<링크1>" "<링크2>"
   ```

   링크마다 `/tmp/reel-read/<아이디>/` 에 다음이 생긴다.
   - `info.txt` — 올린 사람·설명글
   - `transcript.txt` — 말소리 받아쓰기 (시각 포함)
   - `sheet.jpg` — 첫 3초(0·1·2초) + 장면이 바뀔 때마다 1장씩 모은 한 장짜리 사진
   - 사진 게시물(캐러셀)이라 영상이 없으면 `info.txt` 만 생긴다

2. `sheet.jpg` 를 Read 로 직접 본다. 글자가 작으면 `frames/` 의 낱장을 본다.
3. 설명글 + 받아쓰기 + 화면을 합쳐 한국어로 정리한다.
   - 무엇을 소개하는 영상인지 한 줄
   - 첫 3초: 무엇으로 붙잡는지
   - 흐름: 장면별로 무엇이 나오는지
   - 소개하는 도구·기능·프롬프트가 있으면 이름과 하는 일
   - 사용자가 "넣어줘"라고 했으면: 이 앱(content-office)에 이미 있는 것 / 새로 넣을 수 있는 것 / 넣기 어려운 것(이유)을 나눠서
4. 받은 파일은 `/tmp` 에만 둔다. 앱 데이터(영상공장)에 넣지 않는다.

## 주의

- 비공개·로그인이 필요한 게시물은 받지 못한다. 그때는 그렇다고 말하고, 사용자에게 화면 캡처를 부탁한다.
- 남의 릴스는 공부·분석용으로만 쓴다.
